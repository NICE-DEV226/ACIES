# ACIES Logo — Concept & Prompts

## Concept retenu

Le logo représente le **processus décisionnel adaptatif** d'ACIES :
- **Cercles concentriques** = l'espace des actions possibles ( résolutions, niveaux de perception)
- **Centre turquoise** = la décision sélectionnée (le noyau intelligent)
- **Cercles en tirets** = les frontières entre niveaux de sélection
- **Chemins turquoise** = l'adaptation en temps réel (Thompson Sampling)
- **Nœuds noirs** = les actions évaluées en cours de traitement
- **Style main levée** = technique, pas corporate — un croquis d'ingénieur, pas un logo de startup

Ce n'est pas un animal. C'est un **système**.

## Pourquoi ce logo

1. **Immédiatement lisible** — cercle + point = cible/sélection
2. **Communique le concept** — pas juste un joli dessin, c'est le processus ACIES
3. **Reproductible** — fonctionne en monochrome, en petit, partout
4. **Unique** — aucun projet tech n'a ce type de logo
5. **Évolutif** — le même concept peut être animé (les cercles tournent, le point bouge)
